# DC-DC Converter Validation & 12 V Input Protection (ISO 16750-2 / ISO 7637-2)

Two simulation-based automotive electrical projects: a DC-DC converter validation package and an input protection (TVS + reverse-battery) design simulated in LTspice.

| Folder | What it is |
|---|---|
| [dcdc_validation/](dcdc_validation) | Validation package for a 12 V DC-DC converter board: test plan, procedures, traceability matrix and a report template filled with **simulated** data (ISO 16750-2, ISO 7637-2, ISO 10605). |
| [input_protection/](input_protection) | 12 V input protection (TVS + P-FET reverse-battery) simulated in **LTspice** against ISO 7637-2 pulses and load dump, with peak voltage / TVS power / energy vs ratings. |

All results are from simulation. See each folder's README for assumptions and limitations.
